Project Overview

CyberNews is a web-based cyber threat intelligence hub. It collects cybersecurity headlines, vulnerability advisories, community signals, and CVE risk data into one searchable feed. Analysts can generate AI-assisted summaries and reports from selected feed items, while admins can manage generated AI artifacts.

User Roles

  • User: access to the feed and AI features.
  • Admin: user features plus deletion of generated AI artifacts.

Core Features

Unified Threat Feed

Aggregates articles and advisories from NewsAPI, The Hacker News RSS, SecurityWeek RSS, Hacker News, BSI, and CISA advisories.

Vulnerability Intelligence

Enriches CVEs with deterministic data from NVD, CISA KEV, and FIRST EPSS to support risk-based prioritization.

AI Workbench

Uses Gemini to analyze articles, extract CVEs and IOCs, generate source-linked reports, and show retrieval traces.

Safe Reports

Stores generated reports in Firestore and renders them through controlled HTML views instead of trusting arbitrary model output.

Architecture

Frontend

Server-rendered HTML templates with plain CSS and JavaScript. The dashboard includes responsive feed cards, filters, sorting, pagination, and a dark/light/device theme toggle.

Backend

Python Flask application exposing dashboard routes, API endpoints, feed sync, CVE enrichment, authentication, and AI job orchestration.

Data Layer

Google Firestore stores feed items, AI jobs, generated reports, evidence, feedback, detection drafts, and related article context.

Deployment

Containerized with Docker, deployed to Google Cloud Run through Cloud Build. Runtime secrets and API keys are provided through Cloud Run environment variables.

Security and Reliability

  • Role-based access separates regular users from admin-only artifact deletion.
  • Session-based login protects dashboard and API routes.
  • AI output is treated as untrusted and stored as structured report data.
  • External API failures fall back to stored feed data where possible.
  • CVE facts are sourced from deterministic APIs instead of being invented by the LLM.
